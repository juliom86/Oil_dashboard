Methodology & provenance

Read the record, not an invented trend.

Filtered, not downloaded whole

build_data.py reads petroDB over HTTP Range, keeps only Chubut wells, and sorts by well so per-well lookups stay fast.

SQL in the browser

DuckDB-WASM runs the queries locally. Search, filters and aggregates hit the in-memory tables — no server round-trips, no re-download.

Null means not reported

Missing months stay gaps (no interpolation). Totals count only numeric values and show monthly coverage.
